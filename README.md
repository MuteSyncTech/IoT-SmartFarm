# IoT Smart Farm

Sistem Monitoring dan Kontrol Pertanian Berbasis IoT menggunakan ESP32 dan ThingSpeak.

## Deskripsi

Proyek ini dirancang untuk memantau kondisi lingkungan pertanian secara realtime dan mengontrol perangkat secara otomatis maupun manual melalui dashboard web.

## Fitur

* Monitoring suhu udara (DHT21)
* Monitoring kelembapan udara (DHT21)
* Monitoring kelembapan tanah
* Dashboard web realtime
* Kontrol pompa air
* Kontrol kipas
* Mode otomatis dan manual
* Penyimpanan data pada ThingSpeak

## Hardware

* ESP32
* Sensor DHT21
* Sensor Kelembapan Tanah
* Relay 2 Channel
* Pompa Air
* Kipas

## Software

* Arduino IDE
* HTML
* CSS
* JavaScript
* ThingSpeak

## Cara Kerja

1. Sensor membaca suhu, kelembapan udara, dan kelembapan tanah.
2. ESP32 mengirim data ke ThingSpeak.
3. Dashboard menampilkan data secara realtime.
4. Pompa dan kipas dapat dikontrol secara otomatis maupun manual melalui dashboard.
